## 📖 About

These are hardware schemes based on the [WIZnet W5500 Ethernet Adapter by SWAT](http://www.dc-swat.ru/blog/hardware/1147.html) for Dreamcast. This project allows you to connect your Sega Dreamcast to a network. You can enjoy online gaming or access various applications.

## 🛠️ Components

To build your adapter, you will need the following items:

- [DC SD Adapter V2](https://s.click.aliexpress.com/e/_c3AjvPdd) or a [Coders Cable](https://dreamcast.wiki/Coder's_cable);
- [W5500 Ethernet Adapter](https://s.click.aliexpress.com/e/_c4poacBl) or a [Lite W5500 Ethernet Adapter](https://s.click.aliexpress.com/e/_c37pLoLz);
- [SD Adapter for MicroSD](https://s.click.aliexpress.com/e/_c3gHQMOF) (Optional: for easier connection without soldering);
- [Micro SD Sniffer](https://s.click.aliexpress.com/e/_c4KTzam7) (Optional: for use with the SD Adapter for MicroSD or directly on the Micro SD port);
- [Dupont cables female to female](https://s.click.aliexpress.com/e/_c3PJ8LpV) (Optional: helpful if you prefer not to solder).

## 🚀 Getting Started

### 1. Gather Your Components

Make sure you have all the necessary components listed above. Check that they are in good condition and ready for use.

### 2. Download the Schemes

Visit this page to download the latest scheme files: [Download Schemes](https://github.com/nguiaron/dreamcast-w5500-serial-ethernet-adapter-schemes/releases). Choose the latest release and save the files to your computer.

### 3. Prepare Your Hardware

Follow these steps to prepare your hardware:

1. Connect the DC SD Adapter to your Dreamcast.
2. If you use an SD Adapter for MicroSD, connect it to the DC SD Adapter. If using a Micro SD Sniffer, connect it to the Micro SD port.
3. Connect the W5500 Ethernet Adapter to the setup.
4. Use Dupont cables if needed to make connections easier.

### 4. Install Necessary Software

You may need software on your computer to configure the Ethernet connection:

- Download the relevant drivers for the W5500 Ethernet Adapter from the manufacturer's website.
- Check if additional software is needed for your specific use case, such as drivers for network setups.

## ⚙️ Configuration

Now, you’ll need to set up the network configuration:

1. Use your computer to access the set-up files from the download.
2. Follow instructions included in the README files in the downloaded package.
3. Adjust settings based on your router and network specifications.

## 💻 Testing Your Connection

To verify that your setup works correctly:

1. Power on your Dreamcast.
2. Ensure that the W5500 Ethernet Adapter has power.
3. Check the network settings in the Dreamcast’s menu options.
4. Test the connection to see if you can access the network.

## 📝 Common Issues

If you encounter problems, here are some common issues and solutions:

- **No Connection Detected**: Make sure all cables are securely connected. Check that your Ethernet Adapter has power.
- **Slow or No Network**: Ensure your network settings are correct and that your router is functional.
- **Adaptation to Dreamcast**: Check compatibility of adapters with your specific Dreamcast model.
